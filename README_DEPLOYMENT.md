# Deployment Guide

## Project
Pokémon Sustainability Resilience Sandbox

## Files
- app.py
- requirements.txt
- pokemon_sustainability_final_pipeline.joblib
- simulation_reference.joblib
- input_schema.json
- policy_config.json
- README_DEPLOYMENT.md

## Local Run

```bash
pip install -r requirements.txt
python app.py
```

## Hugging Face Spaces
Create a new Gradio Space and upload all files in this package.
